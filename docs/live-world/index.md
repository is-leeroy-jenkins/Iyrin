# Live World

Live World normalizes heterogeneous operational providers into a common `GeoEntity` model for display, analysis, persistence, and agent access.

## Entity Types

- Aircraft.
- Military Aircraft.
- Satellite.
- Vessel.
- Earthquake.
- Fire.
- Infrastructure.
- Camera.
- Map Feature.

## Reliability

- Nine provider-backed sources refresh independently.
- Source state tracks status, last attempt, last success, error, and stale data.
- One provider failure does not stop later providers.
- Previous source data can remain available while marked stale.
- Partial or stale refreshes are not persisted as new history snapshots.

## Advanced Tools

- Tracking & Trails.
- Measurements & Annotations.
- Cross-Layer Analysis.
- Geofencing.
- Historical Replay.
- Agent Tools.

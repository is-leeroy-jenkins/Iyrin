# Interactive Map

Interactive Map provides Iyrin's shared geographic visualization surface and Live World workflow.

## Functions

- Configurable PyDeck map styles.
- Current-location and custom-location context.
- Normalized Live World rendering.
- Per-layer inspection tables.
- Tracking and trails.
- Measurements and annotations.
- Cross-layer spatial analysis.
- Geofencing.
- Historical Replay.
- Agent Tools diagnostics.

See [Live World](../live-world/index.md).

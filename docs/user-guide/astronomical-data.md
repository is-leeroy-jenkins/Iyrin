# Astronomical Data

Astronomical Data provides catalog, orbital, satellite, space-weather, and observation-oriented retrieval.

## Capabilities

- Astroquery catalogs.
- SIMBAD.
- CelesTrak satellite data.
- Near-Earth objects.
- Space-weather sources.
- U.S. Naval Observatory data.
- Satellite and star-oriented scientific sources.

[Celestial Map](celestial-map.md) provides the visualization-oriented complement to these retrieval workflows.

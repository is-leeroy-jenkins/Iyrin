# Artificial Intelligence

Artificial Intelligence provides multi-provider text generation and analysis.

## Providers

- OpenAI.
- Google Gemini.
- Grok / xAI.
- Anthropic Claude.
- Mistral AI.

## Credentials

| Provider | Environment Variable |
|---|---|
| OpenAI | `OPENAI_API_KEY` |
| Gemini | `GEMINI_API_KEY` |
| Grok / xAI | `XAI_API_KEY` |
| Claude | `CLAUDE_API_KEY` |
| Mistral | `MISTRAL_API_KEY` |

Live World callable tools remain provider-neutral and can be registered by external agent frameworks.

# Site Crawler

Site Crawler retrieves web content from a target URL and supports recursive crawling.

## Extracted Content

- Page title and text.
- Raw HTML.
- Headings and paragraphs.
- Lists and tables.
- Articles, sections, divisions, and blockquotes.
- Hyperlinks and images.

Retrieved content can participate in chunking, embeddings, and vector persistence when the active workflow exposes processing controls.
